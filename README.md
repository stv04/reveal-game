# Revela con Fe 🎲

Juego de cartas digital con preguntas y retos divertidos para grupos cristianos.

## Características

- 💡 6+ preguntas por categoría
- 🔄 Las cartas no se repiten hasta reiniciar
- 📱 Diseñado para móvil y escritorio
- ✨ Efectos especiales en cartas importantes
- 📋 Copia y comparte preguntas
- 📜 Historial de cartas jugadas

## Categorías

- 🌟 **Luz**: Situaciones divertidas y experiencias cotidianas
- ✝️ **Fe**: Reflexiones sobre tu camino espiritual
- 🤝 **Comunidad**: Conexión con el grupo y la iglesia
- 📖 **Biblia**: Conocimiento bíblico e historias
- 🎯 **Especial**: Retos, oraciones y momentos de adoración

## Cómo jugar

1. Abre `revela.html` en tu navegador
2. Elige un mazo o toca "🎲 Aleatorio"
3. Lee la pregunta y responde
4. Las cartas especiales (🙏📖🎯) tienen efectos visuales
5. Usa los botones para:
   - "🔁 Repetir" última carta
   - "♻️ Reiniciar mazos" cuando se agoten
   - "📋 Copiar" para compartir
   - "Limpiar" para borrar historial

## Desarrollo

Los archivos del proyecto están organizados así:
- `revela.html`: Estructura y contenido
- `styles.css`: Estilos y responsive design
- `script.js`: Lógica del juego y animaciones

Para modificar:
1. Edita `script.js` para añadir/cambiar preguntas
2. Ajusta `styles.css` para personalizar diseño
3. El juego no requiere servidor web
